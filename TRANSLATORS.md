# Translators

Everyone whose text is in the mod. This file is the source of truth — the release
notes, the Steam CREDITS block and the in-game notebook page are all filled in from
it, so if a name is wrong here it is wrong everywhere.

| Language | Code | Translator | First shipped in |
|---|---|---|---|
| English | `EN` | SlavaPo (author) | 1.0 |
| Russian | `RU` | SlavaPo (author) | 1.0 |

*Your language could be the third row. See [CONTRIBUTING.md](CONTRIBUTING.md).*

---

**A name is spelled the way its owner spells it.** If you want a different handle,
different capitalisation, a link, or your name taken off this list entirely, say so
in an issue and it will be changed — including in the mod, at the next release.

One thing cannot be taken back after the fact: the notebook page is written into a
save **when the character is created**, so a player who rolled a character while
your name was in the book keeps that book. That is also why the page is yours to
write rather than something added on your behalf — see
[CONTRIBUTING §6](CONTRIBUTING.md#6-your-credit-page).
